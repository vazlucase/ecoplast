# Ecoplast — Site Institucional

Site empresarial single-page para a **Ecoplast Soluções Ambientais**, desenvolvido com foco em UX, performance e conversão.

## Estrutura

```
ecoplast/
├── index.html        ← Site completo (HTML + CSS + JS inline)
├── assets/
│   └── logo.png      ← Logomarca oficial da Ecoplast
└── README.md
```

## Seções

1. **Nav** — Fixa com blur, links de navegação e CTA
2. **Hero** — Headline principal, CTAs e cards animados
3. **Sobre** — 4 pilares de atuação da empresa
4. **O Problema** — Desafios da limpeza urbana convencional
5. **A Solução** — Fluxo de biorremediação em 3 etapas
6. **Aplicações** — 8 ambientes de aplicação
7. **Benefícios** — 7 benefícios da tecnologia
8. **Modelo de Gestão** — Pilares + Economia Circular
9. **Inovação** — EPIs Hidrossolúveis e Biodegradáveis
10. **Visão** — Propósito da empresa
11. **Contato** — Canais reais + Formulário
12. **Footer** — Links e informações

## Como usar

Basta abrir `index.html` em qualquer navegador moderno. Não requer servidor nem instalação.

Para publicar online, faça upload dos arquivos na raiz de qualquer hospedagem estática (Vercel, Netlify, GitHub Pages, cPanel, etc.).

## Tecnologias

- HTML5 semântico
- CSS3 com custom properties (variáveis)
- JavaScript vanilla (scroll animations, nav behavior)
- Google Fonts: Syne + DM Sans
